donor.cpr - the project every Cubase project is built from.

A .cpr can only be written by editing one Cubase wrote, so this holds one of
each kind of record: an audio track carrying an audio event, an instrument
track carrying MIDI parts and an insert effect, and folders. Everything a
REAPER project needs is made by duplicating the matching kind and rewriting
its contents - names, plug-in identity and state, file references, notes.

It was cut down from a real Cubase project: 49 tracks reduced to 4, with the
samplers removed so it opens quickly and on any machine.

Replace it only with another real Cubase project containing at least one
audio event and one instrument track with a MIDI part.
